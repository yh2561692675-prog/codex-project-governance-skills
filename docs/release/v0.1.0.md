# Project Development Governance v0.1.0

Status: release candidate pending formal release approval.

Project Development Governance is a reusable collection of Codex Skills for bounded, auditable, and recoverable project work. This candidate packages the six installable Skills, their contracts and references, the portable installer/uninstaller, governance fixtures, cross-platform CI contracts, security checks, and the CycloneDX SBOM.

## Candidate verification

- Candidate assets are generated from one fixed public Git commit.
- Source archive and per-Skill bundles use a fixed archive timestamp and sorted file order for reproducible content hashes.
- SHA-256 checksums cover every distributable archive, the SBOM, and these release notes.
- Fresh verification runs layout checks, CI contract checks, portable install/uninstall, and the synthetic governance behavior evaluation.

## Scope boundary

This document describes engineering and installation evidence for v0.1.0. It does not claim independent adoption, human acceptance, formal data authorization, or approval for any external program. A formal Git tag and GitHub Release require the maintainer's explicit decision after candidate verification.
